# Simplify Branch Optimization Plan

## Goal

Create and work on the `simplify` branch, then reduce project friction without changing the extension's intended behavior.

## Acceptance Criteria

- Current branch is `simplify`.
- Repository-level optimization changes are scoped and reviewable.
- No generated or dependency output is accidentally committed.
- `npm run lint:js` passes.
- `npm run lint:css` passes.
- `npm run build` passes.
- Final report names changed files and verification commands.

## Notes

- Live `git status` is authoritative; older status documents may be stale.
- Keep source behavior intact unless an existing bug fix is clearly required by the current code.
